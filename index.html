客户端

四类客户端，配置流程一致

sbairport 订阅链接可直接填入以下客户端。配置仅涉及服务器地址与本地端口，不调整系统代理设置。

桌面端 · Clash macOS / Windows

从用户中心复制订阅链接，粘贴至 Profiles → From URL，启用后即可看到节点组。本地端口默认 7890。

桌面端 · v2rayN Windows

在订阅分组中添加订阅地址，点击更新订阅后选择合适的节点右键设为活动服务器。

移动端 · Shadowrocket iOS

主页右上角添加订阅，粘贴链接并启用。允许添加 VPN 配置后回到首页切换节点。

移动端 · Clash for Android Android

配置 → 新建订阅 → 填入 URL → 保存并启用。设置页可调整系统代理模式为 Rule 或 Global。

使用说明

从购买到启用的四个步骤

第一步 · 选择套餐

  • 根据同时在线的设备数选择档位。
  • 月付与年付均可，随时在用户中心切换。
  • 套餐升级当月按差价补足。

第二步 · 取得订阅链接

  • 付款完成后进入用户中心。
  • 点击"复制订阅 URL"并妥善保存。
  • 链接包含 token,请勿对外公开。

第三步 · 配置客户端

  • 在任一支持订阅的客户端中添加 URL。
  • 更新订阅后选择低延迟节点。
  • 系统代理模式按需切换 Rule 或 Global。

第四步 · 日常维护

  • 每月初重置流量额度,请留意用量提示。
  • 客户端更新后建议重新拉取订阅。
  • 遇到节点变动可在 FAQ 中查看处理方式。

常见问题

订阅、流量与节点

以下条目按订阅生命周期顺序排列,使用 details 折叠以便快速查阅。

订阅链接是否每次都会变化?

订阅 URL 在套餐有效期内保持不变。token 用于识别用户身份,请勿泄露至公共渠道。

若怀疑链接外泄,可在用户中心重置 token,旧链接即刻失效。

流量如何计算?是否会重置?

流量按自然月重置,每月 1 日 00:00(UTC+8)重新计数,未使用部分不结转。

上行与下行均计入配额,本地代理至客户端之间的流量按实际字节数统计。

套餐之间可以升降级吗?

支持随时升降级。升级时按剩余天数补足差价,降级则在下一计费周期生效。

同一计费周期内反复切换,差额会在用户中心的结算页显示明细。

设备数超额登录会怎样?

超出套餐限制的新设备将被拒绝登录,已在使用的设备不受影响。

可在客户端设置中登出闲置设备,以腾出位置。

节点列表为空该如何排查?

首先在客户端中手动更新订阅链接,确认网络可达订阅域名。

若节点仍为空,检查客户端时间是否准确,误差大于 90 秒会导致协议握手失败。

套餐到期后订阅会保留多久?

套餐到期后订阅在 72 小时内仍可访问,期间续费可恢复全部配置。

超过 72 小时未续费,订阅链接与节点配置将被回收,重新购买后重新下发。

支持哪些付款方式与发票?

用户中心提供常用在线支付方式,具体以付款页所示为准。

需要发票的订单请在付款前提交抬头信息,逾期不再补开。
